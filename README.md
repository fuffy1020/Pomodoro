# 專注之間

> 留一段時間，給一件重要的事。

「專注之間」是一款安靜、簡潔的繁體中文番茄鐘。它把專注、短休息與長休息整理成自然的工作節奏，讓人不必管理複雜的清單，也能清楚知道此刻該做什麼。

## 專注節奏

預設以 25 分鐘專注、5 分鐘短休息組成循環，每完成四次專注便進入較長的休息。每個階段都能依自己的步調調整，也能隨時暫停、繼續、提早完成或跳過休息。

計時器會依真實時間運作。切換頁面、重新整理或暫時離開瀏覽器，都不會讓進度失去準確性。主畫面也會顯示今日累積的專注時間，讓成果自然地留在視線裡。

## 專注紀錄

完成的專注會成為清楚的時間紀錄。歷史頁提供每日與每週統計、專注次數、趨勢圖表和個別時段明細，也能將所有紀錄匯出為 CSV。

暫停與休息時間不會被算進專注成果；跨越午夜的時段則會依實際發生的日期分配，讓每天與每週的統計保持準確。

## 跨裝置同步

使用 Email Magic Link 登入後，專注紀錄可以在不同裝置之間同步。網路暫時中斷時，完成的紀錄會先保存在裝置上，待連線恢復後再繼續同步。

每個帳號只能存取自己的專注紀錄。未登入時也能使用本機模式，保留一個不打擾專注流程的簡單選擇。

## 設計想法

介面以低彩度色彩、清楚的層級和足夠留白為主，讓計時本身成為畫面的中心。專注是一段需要被保護的時間，「專注之間」希望讓開始這件事變得更輕一些。
